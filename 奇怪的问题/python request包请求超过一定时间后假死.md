TCP Keep-Alive（保活探测）的默认开关

curl 命令：默认开启 TCP Keep-Alive。它会每隔一段时间（通常 60秒）发送一个空的“心跳”探测包给服务器，告诉沿途的所有网络设备（NAT网关、防火墙、交换机）：“这个连接还活着，别删我的会话记录”。

Python requests 包：底层依赖 urllib3，默认关闭应用层的 TCP Keep-Alive（依赖于操作系统默认值，而 Windows/Linux 默认的探测间隔通常是 7200秒（2小时），太长了）。
