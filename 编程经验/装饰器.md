### 装饰器 Decorator
这个东西看着也像是切面编程的感觉,只不过是方法前后都切一下

python万物届对象，即便是函数也不例外， 函数也可以作为一个对象在函数中传递，装饰器利用这个特性，允许程序员在不改动已有代码的情况，甚至对于一个加密的函数（黑盒）进行修改时，允许在不改动已有代码情况下，添加新的功能。
最简单的例子，我现在有性能问题，一个流程1小时，我想具体看看哪个函数跑得慢
首先定义一个装饰器：
import time

def timer(func)
  def warpper(*args,**kwargs):
      start = time.time()
      result= func(*args,**kwargs)
      end =time.time()
      print(f"{func.__name__} 耗时 { end-start:.4f} 秒")


之后回到我们的代码，再每个函数上面加上@和你的函数名 比如：

### @timer
def datacollecton():


### @timer
def insertdb():

在控制台就会打出类似:
datacollecton 耗时 100秒
insertdb 耗时20 秒
