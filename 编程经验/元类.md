### 元类

首先python有个方法是type（） 可以检测每个方法或者类的类型
当你type一个类时候 会返回type类型 有点java的object的感觉， 不过java是继承，python是所有类都基于这个type实例化



元类可以自己重写

class test(type):
  def __new__(mcs,name,bases,namespace)

mcs可以当做占位符，很少会修改，它的作用类似让编译器知道这个类是什么类型，好去实例化这个类

name是当你用这个元类创造其他类的时候，类的名字会存到这个name
如 new good(test), 那么name就是good

  bases是存储这个方法的所有父类，比如
  Class human:

  Class oldman(human)

  class yongman(oldman)

  这时候你看yongman.bases内容就是(oldman,human) 主要目的是看这个方法都继承了哪些方法，自动实现或者要满足哪些父类的方法

  namespace就是子类实例化时候带的所有属性和方法，元类可以通过检查 namespace 中是否有某个 key” 是正确的用法。例如强制要求子类必须定义 name 属性。

class test(type):
  def __new__(mcs,name,bases,namespace):
       if bases:
         # 确定方法是基于这个元类新建的，而不是自己
         if "ishuman" not in namespace:
             raise TypeError(
                 f"ishuman must defined {name}"
             )
       return type.__new__(mcs,name,bases,namespace)
要注意元类任何情况必须return，否则子类会报nonetype exception.
